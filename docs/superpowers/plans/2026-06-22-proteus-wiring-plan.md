# Proteus 原理图连接实施计划

> **给后续执行者说明：** 本计划用于逐步完成 Proteus 原理图搭建。每一步使用复选框格式，方便边画图边检查。

**目标：** 完成“基于 AT89C51 的 PG128128A 液晶电子密码锁”Proteus 8 Professional 仿真原理图。

**总体结构：** 系统以 AT89C51 为主控芯片，PG128128A 图形液晶负责显示，4x4 矩阵键盘负责输入，LED 模拟电子锁状态，蜂鸣器和状态灯负责报警提示。大屏幕显示效果更好，适合展示欢迎界面、密码输入、锁定倒计时和菜单状态。

**使用工具与器件：** Proteus 8 Professional、AT89C51、PG128128A、BUTTON、BUZZER、C3225X7R1C475K、CRYSTAL、KEYPAD-TRELLIS-C1、LED-GREEN、LED-RED、LED-YELLOW、RES、RESPACK-8。

---

## 任务 2：连接 AT89C51 基础电路

**涉及文件：**
- 修改：`source/password_lock.pdsprj`

- [ ] **步骤 1：连接电源**

```text
AT89C51 第 40 脚 VCC -> +5V
AT89C51 第 20 脚 GND -> GND
```

- [ ] **步骤 2：连接晶振电路**

```text
AT89C51 第 18 脚 XTAL2 -> CRYSTAL 一端
AT89C51 第 19 脚 XTAL1 -> CRYSTAL 另一端
```

说明：标准实物电路中晶振两端各接一个约 30pF 电容到 GND。你当前元件列表里没有普通小电容时，Proteus 仿真可以先只接 CRYSTAL，并在 AT89C51 属性中设置 11.0592MHz。

- [ ] **步骤 3：连接复位电路**

```text
AT89C51 第 9 脚 RST -> C3225X7R1C475K -> +5V
AT89C51 第 9 脚 RST -> 10k 电阻 -> GND
AT89C51 第 9 脚 RST -> 复位按键 -> +5V
```

说明：上电时电容产生高电平复位；按下复位键时也可手动复位。`C3225X7R1C475K` 可按 4.7uF 电容理解，仿真中用于复位足够。

- [ ] **步骤 4：连接程序存储器选择脚**

```text
AT89C51 第 31 脚 EA/VPP -> +5V
```

说明：EA 接高电平表示使用片内程序存储器，这是 Proteus 仿真 AT89C51 时常用接法。

## 任务 3：连接 HDG12864L-4 图形液晶模块

**涉及文件：**
- 修改：`source/password_lock.pdsprj`

- [ ] **步骤 1：连接液晶电源与对比度**

```text
HDG12864L-4 第 14 脚 VDD  -> +5V
HDG12864L-4 第 15 脚 GND  -> GND
HDG12864L-4 第 16 脚 VOUT -> 先悬空或按 Proteus 默认
```

说明：`HDG12864L-4` 是 12864 图形液晶，不是字符 LCD。它的显示效果更好，但程序必须使用 12864 图形液晶驱动，不能继续使用 LCD1602 的显示函数。

- [ ] **步骤 2：连接液晶控制线**

```text
HDG12864L-4 第 1 脚 CS1 -> AT89C51 P2.3，第 24 脚
HDG12864L-4 第 2 脚 RES -> AT89C51 P2.4，第 25 脚
HDG12864L-4 第 3 脚 A0  -> AT89C51 P2.0，第 21 脚
HDG12864L-4 第 4 脚 RW  -> AT89C51 P2.1，第 22 脚
HDG12864L-4 第 5 脚 E   -> AT89C51 P2.2，第 23 脚
```

- [ ] **步骤 3：连接液晶数据线**

```text
HDG12864L-4 第 6 脚 D0  -> AT89C51 P0.0，第 39 脚
HDG12864L-4 第 7 脚 D1  -> AT89C51 P0.1，第 38 脚
HDG12864L-4 第 8 脚 D2  -> AT89C51 P0.2，第 37 脚
HDG12864L-4 第 9 脚 D3  -> AT89C51 P0.3，第 36 脚
HDG12864L-4 第 10 脚 D4 -> AT89C51 P0.4，第 35 脚
HDG12864L-4 第 11 脚 D5 -> AT89C51 P0.5，第 34 脚
HDG12864L-4 第 12 脚 D6 -> AT89C51 P0.6，第 33 脚
HDG12864L-4 第 13 脚 D7 -> AT89C51 P0.7，第 32 脚
```

- [ ] **步骤 4：给 P0 口加上拉电阻**

AT89C51 的 P0 口是开漏结构，作为普通 I/O 使用时需要上拉电阻：

```text
P0.0 -> 10k -> +5V
P0.1 -> 10k -> +5V
P0.2 -> 10k -> +5V
P0.3 -> 10k -> +5V
P0.4 -> 10k -> +5V
P0.5 -> 10k -> +5V
P0.6 -> 10k -> +5V
P0.7 -> 10k -> +5V
```

也可以直接使用一个 8 路 10k 电阻排连接到 P0 口。

## 任务 4：连接 4x4 矩阵键盘

**涉及文件：**
- 修改：`source/password_lock.pdsprj`

- [ ] **步骤 1：优先使用 BUTTON 手动搭建 4x4 矩阵键盘**

你当前元件库里的 `KEYPAD-TRELLIS-C1` 外观是 4x4 键盘，但它不一定是普通的 8 线矩阵键盘。如果它没有明确标出 `R1-R4` 和 `C1-C4` 引脚，建议不要直接用于本设计。

最稳妥的做法是使用 16 个 `BUTTON` 搭建矩阵键盘。每个按钮连接一根行线和一根列线，形成 4 行 4 列。

- [ ] **步骤 2：连接键盘行线**

```text
键盘 R1 -> AT89C51 P1.0，第 1 脚
键盘 R2 -> AT89C51 P1.1，第 2 脚
键盘 R3 -> AT89C51 P1.2，第 3 脚
键盘 R4 -> AT89C51 P1.3，第 4 脚
```

- [ ] **步骤 3：连接键盘列线**

```text
键盘 C1 -> AT89C51 P1.4，第 5 脚
键盘 C2 -> AT89C51 P1.5，第 6 脚
键盘 C3 -> AT89C51 P1.6，第 7 脚
键盘 C4 -> AT89C51 P1.7，第 8 脚
```

- [ ] **步骤 4：16 个 BUTTON 的具体连接方式**

```text
第一行：
按键 1：R1 与 C1 之间
按键 2：R1 与 C2 之间
按键 3：R1 与 C3 之间
按键 A：R1 与 C4 之间

第二行：
按键 4：R2 与 C1 之间
按键 5：R2 与 C2 之间
按键 6：R2 与 C3 之间
按键 B：R2 与 C4 之间

第三行：
按键 7：R3 与 C1 之间
按键 8：R3 与 C2 之间
按键 9：R3 与 C3 之间
按键 C：R3 与 C4 之间

第四行：
按键 *：R4 与 C1 之间
按键 0：R4 与 C2 之间
按键 #：R4 与 C3 之间
按键 D：R4 与 C4 之间
```

- [ ] **步骤 5：程序中使用的键位布局**

```text
1 2 3 A
4 5 6 B
7 8 9 C
* 0 # D
```

建议按键功能：

```text
0-9：输入密码
#：确认
*：清除或返回
A：修改密码
B：查看开锁次数
C：退格
D：管理员清零功能
```

## 任务 5：连接电子锁、蜂鸣器和状态灯

**涉及文件：**
- 修改：`source/password_lock.pdsprj`

- [ ] **步骤 1：连接电子锁指示灯**

使用绿色 LED 模拟电子锁打开：

```text
AT89C51 P3.0，第 10 脚 -> 330R 电阻 -> 绿色 LED 正极
绿色 LED 负极 -> GND
```

程序中 P3.0 输出高电平时，绿色 LED 点亮，表示“开锁成功”。

- [ ] **步骤 2：连接蜂鸣器**

优先使用有源蜂鸣器，仿真更简单：

```text
AT89C51 P3.1，第 11 脚 -> 有源蜂鸣器正极
有源蜂鸣器负极 -> GND
```

如果 Proteus 中蜂鸣器无法正常响，或提示驱动能力不足，可以改用三极管驱动：

```text
AT89C51 P3.1 -> 1k 电阻 -> NPN 三极管基极
NPN 三极管发射极 -> GND
NPN 三极管集电极 -> 蜂鸣器负极
蜂鸣器正极 -> +5V
```

- [ ] **步骤 3：连接报警状态灯**

```text
AT89C51 P3.2，第 12 脚 -> 330R 电阻 -> 红色 LED 正极
红色 LED 负极 -> GND
```

红色 LED 用于表示密码错误、报警或锁定状态。

- [ ] **步骤 4：连接锁定状态灯，可选**

```text
AT89C51 P3.3，第 13 脚 -> 330R 电阻 -> 黄色 LED 正极
黄色 LED 负极 -> GND
```

黄色 LED 可用于表示系统处于锁定状态，属于加分展示功能。

## 任务 7：原理图自查清单

**涉及文件：**
- 修改：`source/password_lock.pdsprj`

- [ ] **步骤 1：检查电源相关连接**

确认：

```text
AT89C51 的 VCC 和 GND 已连接。
HDG12864L-4 的 VDD 和 GND 已连接。
EA/VPP 已接 +5V。
所有模块共地。
```

- [ ] **步骤 2：检查 12864 液晶连接**

确认：

```text
HDG12864L-4 VDD 和 GND 已连接。
HDG12864L-4 A0/RW/E 分别连接 P2.0/P2.1/P2.2。
HDG12864L-4 CS1/RES 分别连接 P2.3/P2.4。
HDG12864L-4 D0-D7 分别连接 P0.0-P0.7。
P0.0-P0.7 已加 10k 上拉电阻。
```

- [ ] **步骤 3：检查矩阵键盘连接**

确认：

```text
键盘 R1-R4 连接 P1.0-P1.3。
键盘 C1-C4 连接 P1.4-P1.7。
行线和列线没有短接。
```

- [ ] **步骤 4：检查输出模块连接**

确认：

```text
P3.0 控制绿色开锁 LED。
P3.1 控制蜂鸣器。
P3.2 控制红色报警 LED。
P3.3 可选控制黄色锁定 LED。
```
