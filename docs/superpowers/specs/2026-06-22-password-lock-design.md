# 基于 AT89C51 的 12864 液晶电子密码锁设计

## 1. 选题定位

本课程设计选择“单片机电子密码锁”，实现一个带 12864 图形液晶显示、矩阵键盘输入、密码修改、错误报警、锁定保护和开锁记录的交互式电子密码锁系统。

该方案比基础密码锁增加了安全保护和管理功能，适合在 Keil C51 与 Proteus 8 Professional 中完成仿真演示，也便于撰写完整的课程设计报告。

## 2. 设计目标

系统以 AT89C51 为控制核心，通过 4x4 矩阵键盘输入 6 位数字密码，通过 HDG12864L-4 图形液晶显示当前状态和操作提示，通过 LED 或继电器模拟电子锁动作，通过蜂鸣器实现报警提示。

系统应完成以下功能：

1. 上电显示欢迎界面。
2. 默认进入锁定状态，提示输入 6 位密码。
3. 输入密码时 LCD 使用星号隐藏显示。
4. 密码正确后开锁 5 秒，然后自动关锁。
5. 密码错误时蜂鸣器报警并提示错误。
6. 连续输错 3 次后系统锁定 30 秒，LCD 显示倒计时。
7. 支持修改密码，修改前必须验证原密码。
8. 记录成功开锁次数，并支持查看。
9. 支持管理员清零开锁次数。

## 3. 硬件组成

主要硬件模块如下：

| 模块 | 器件 | 作用 |
| --- | --- | --- |
| 主控模块 | AT89C51 或 AT89C52 | 负责键盘扫描、显示控制、密码判断、报警和开锁控制 |
| 显示模块 | HDG12864L-4 | 显示密码输入、系统状态、错误提示、倒计时和开锁次数 |
| 输入模块 | 4x4 矩阵键盘 | 输入密码、确认、清除、退格、进入菜单 |
| 执行模块 | LED 或继电器 | 模拟电子锁开关状态 |
| 报警模块 | 有源蜂鸣器 | 密码错误、锁定和操作提示 |
| 基础电路 | 晶振、复位、电源 | 保证单片机正常工作 |

| 单片机端口 | 连接对象 | 说明 |
| --- | --- | --- |
| P0.0-P0.7 | HDG12864L-4 D0-D7 | 液晶数据线，P0 口需要上拉电阻 |
| P2.0 | HDG12864L-4 A0 | 数据/命令选择 |
| P2.1 | HDG12864L-4 RW | 读写选择 |
| P2.2 | HDG12864L-4 E | 使能信号 |
| P2.3 | HDG12864L-4 CS1 | 片选信号 |
| P2.4 | HDG12864L-4 RES | 液晶复位 |
| P1.0-P1.3 | 矩阵键盘行线 | 键盘扫描输出 |
| P1.4-P1.7 | 矩阵键盘列线 | 键盘扫描输入 |
| P3.0 | 开锁 LED 或继电器 | 高电平或低电平控制开锁，按电路确定 |
| P3.1 | 蜂鸣器 | 报警提示 |
| P3.2 | 报警状态灯 | 可选扩展 |
| P3.3 | 开锁状态灯 | 可选扩展 |

## 5. 键盘功能定义

4x4 矩阵键盘布局建议如下：

```text
1 2 3 A
4 5 6 B
7 8 9 C
* 0 # D
```

按键含义：

| 按键 | 功能 |
| --- | --- |
| 0-9 | 输入数字密码 |
| # | 确认输入 |
| * | 清除或返回 |
| A | 进入修改密码功能 |
| B | 查看开锁次数 |
| C | 退格 |
| D | 管理员功能，清零开锁次数 |

## 6. 软件结构

程序采用模块化设计，建议划分为以下部分：

1. 12864 显示模块：负责图形液晶初始化、清屏、字符显示、数字显示。
2. 键盘扫描模块：负责矩阵键盘扫描、按键消抖和键值返回。
3. 密码管理模块：负责密码保存、密码比较、密码修改。
4. 状态控制模块：负责锁定、输入、开锁、修改密码、查看记录等状态切换。
5. 报警控制模块：负责蜂鸣器短鸣、长鸣和锁定提示。
6. 计时模块：负责 5 秒自动关锁和 30 秒锁定倒计时。

## 7. 系统状态设计

系统建议采用状态机思路实现，主要状态如下：

| 状态 | 说明 |
| --- | --- |
| WELCOME | 上电欢迎界面 |
| LOCKED | 锁定状态，等待输入密码 |
| INPUT | 正在输入密码 |
| UNLOCKED | 密码正确，电子锁打开 |
| ERROR | 密码错误，报警提示 |
| LOCKOUT | 连续输错 3 次，系统锁定倒计时 |
| CHANGE_OLD | 修改密码时输入原密码 |
| CHANGE_NEW | 输入新密码 |
| CHANGE_CONFIRM | 再次输入新密码确认 |
| VIEW_COUNT | 查看开锁次数 |
| ADMIN_CLEAR | 清零开锁次数 |

## 8. 核心流程

主流程：

1. 系统初始化 LCD、键盘、蜂鸣器和电子锁端口。
2. LCD 显示欢迎界面。
3. 进入锁定状态，提示输入密码。
4. 用户输入 6 位密码后按 `#` 确认。
5. 系统比较输入密码与当前密码。
6. 如果正确，开锁并累计开锁次数，5 秒后自动关锁。
7. 如果错误，错误次数加 1 并蜂鸣器报警。
8. 如果连续错误达到 3 次，进入 30 秒锁定倒计时。
9. 锁定结束后清除错误次数，返回锁定状态。

修改密码流程：

1. 用户按 `A` 进入修改密码。
2. 系统要求输入原密码。
3. 原密码正确后输入新 6 位密码。
4. 再次输入新密码确认。
5. 两次输入一致则保存新密码，否则提示修改失败。

查看和清零流程：

1. 用户按 `B` 查看开锁次数。
2. 用户按 `D` 进入管理员清零功能。
3. 清零前要求输入当前密码。
4. 验证通过后清零开锁次数。

## 9. 异常与边界处理

1. 输入不足 6 位时按 `#`，提示位数不足。
2. 输入超过 6 位时忽略多余数字或蜂鸣器提示。
3. `C` 可删除最后一位输入。
4. `*` 可清空当前输入或返回上一级。
5. 锁定倒计时期间禁用普通输入。
6. 修改密码时两次新密码不一致，需要重新输入。
7. 开锁次数超过显示范围时可保持最大值或循环计数，报告中建议设为 0-9999。

## 10. 测试方案

建议在 Proteus 中完成以下测试：

1. 上电后 LCD 是否显示欢迎界面。
2. 输入正确 6 位密码后是否开锁 5 秒。
3. 输入错误密码后是否报警。
4. 连续输错 3 次后是否进入 30 秒锁定。
5. 锁定倒计时期间按键是否无效。
6. 修改密码功能是否需要原密码验证。
7. 新密码修改后，旧密码是否失效，新密码是否可开锁。
8. 成功开锁后次数是否加 1。
9. 管理员清零后次数是否归零。
10. 退格、清除、确认等按键是否工作正常。

## 11. 报告亮点

报告中可以重点突出以下创新或扩展功能：

1. HDG12864L-4 大屏人机交互界面。
2. 4x4 矩阵键盘节省 I/O 资源。
3. 密码隐藏显示，提高安全性。
4. 连续输错锁定机制，防止暴力破解。
5. 密码修改功能，提高实用性。
6. 开锁次数记录和管理员清零功能，增强管理能力。
7. 状态机程序设计，逻辑清晰、便于扩展。

## 12. 实施边界

本设计主要完成 Proteus 仿真和 Keil C51 程序设计，不进行实物焊接。密码默认保存在程序变量中；如果课程时间允许，可扩展为掉电保存，但 AT89C51 本身不带 EEPROM，需额外增加存储芯片，当前方案不作为必做内容。
