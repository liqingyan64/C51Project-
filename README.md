# 《单片机原理与应用》课程设计报告 LaTeX 模板

这个工程用 XeLaTeX 复刻 Word 参考模板的页面和封面版式。

## 编译

在本目录运行：

```powershell
xelatex main.tex
xelatex main.tex
```

## 填写信息

打开 `main.tex`，修改文件开头的这些命令：

```tex
\newcommand{\ReportTitle}{}
\newcommand{\CollegeName}{人工智能与信息安全学院}
\newcommand{\MajorName}{}
\newcommand{\GradeName}{}
\newcommand{\StudentId}{}
\newcommand{\StudentName}{}
\newcommand{\ReportDate}{2026年 6月22日}
```

留空时会保留模板的下划线填写区。
